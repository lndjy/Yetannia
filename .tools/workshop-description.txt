[b]【只支持 beta 版 · BETA BRANCH ONLY】[/b]

本 Mod 只在《杀戮尖塔 2》的 [b]beta 分支[/b]上开发与测试。正式分支（非 beta）不保证能加载，
可能出现角色不出现、卡图丢失、事件对话报错等问题。请在 Steam 里把游戏切到 beta 分支后再使用。

[hr][/hr]

[h2]这个 Mod 加了什么[/h2]

[b]新角色：耶坦尼娅 Yetannia[/b]

[list]
[*][b]82 张卡牌[/b]，全部围绕「预见」设计，强度参考《杀戮尖塔 1》的角色、高于《杀戮尖塔 2》的角色；补全了《杀戮尖塔 1》观者那套尚未完成的预见体系，全部由作者手工设计
[*][b]关键词「先知」[/b]：当此牌从抽牌堆进入弃牌堆时，触发它的先知效果
[*][b]中英双语文案[/b]：卡牌、能力、遗物与关键词文本随游戏语言在中文 / 英文之间切换（其他语言回退中文）
[*][b]初始遗物「先知发饰」[/b]；在欧洛巴斯处替换初始遗物时，会升级为「先知头冠」
[*][b]11 处语音[/b]：攻击、技能、受到致命伤、选人、开局、战斗开始、卡牌奖励、营火、商店、事件、遗物
[*][b]九位先古之民的专属对话[/b]（涅奥 / 欧洛巴斯 / 佩尔 / 瓦库 / 坦克斯 / 特兹卡塔拉 / 诺奴佩普 / 达弗 / 建筑师）
[*]战斗、营火、商人三处都用[b]会动的角色[/b]，不是静态立绘
[*]选人界面、能量球、地图标记、卡牌与遗物图标均为独立美术
[/list]

[h2]语音语言[/h2]

游戏设置里会多出一项 [b]语音语言[/b]，可选 [b]中文 / 日语 / 关闭[/b]。

「关闭」只关掉她的语音，[b]不会影响游戏原版音效[/b]。

[h2]卡牌数值（原版 / 东尼测试版）[/h2]

设置里还会多一项 [b]卡牌数值[/b]，可选 [b]原版 / 东尼测试版[/b]。[b]原版[/b]是正式发布的数值；[b]东尼测试版[/b]对 12 张卡（试探、合击、修顿、有条不紊、制敌机先、积厚成势、请君入瓮、背水一战、交叉防御、临危不乱、夹击之势、冰刃轮舞）采用另一套数值草案，[b]其余 70 张卡两档完全一致[/b]。

卡牌数值和卡面文字都是游戏加载时生成的，所以[b]切换后需要重启游戏才会生效[/b]。

[h2]安装[/h2]

1. 先订阅 [b]BaseLib[/b]（版本 ≥ 3.4.7）。没有它本 Mod 不会加载，日志里也不会有任何 [code][Yetannia][/code] 字样。
2. 在 Steam 里把《杀戮尖塔 2》切到 [b]beta 分支[/b]，然后[b]从 Steam 启动[/b]游戏。
3. 在游戏主菜单打开 [b]Mod 列表[/b]，确认 BaseLib 和 Yetannia 都已[b]启用[/b]，然后重启游戏。
4. 选人界面应能看到耶坦尼娅（角色不需要解锁）。

如果你用的是压缩包版本：把 [code]Yetannia[/code] 文件夹解压到 [code]...\Slay the Spire 2\mods\[/code]，得到 [code]mods\Yetannia\Yetannia.dll[/code]、[code]Yetannia.json[/code]、[code]Yetannia.pck[/code] 并列的结构，再按上面的第 2–4 步操作。

[h1]English[/h1]

[b]BETA BRANCH ONLY[/b] — this mod is developed and tested on the [b]beta branch[/b] of Slay the Spire 2 only. Please switch the game to the beta branch in Steam first.

[b]Yetannia[/b] is a new character with [b]82 cards[/b] built around Scry, her own relic, the [b]Prophet[/b] keyword, Chinese / Japanese voice lines, and dedicated dialogue for all nine Ancients.

[h2]Card numbers: Original / Tony Test Build[/h2]

The settings screen gains a [b]Card Numbers[/b] switch. [b]Tony Test Build[/b] changes 12 cards — Probe, Pincer Strike, Xiudun, Methodical, Seize the Initiative, Accumulate Might, Into the Trap, Last Stand, Cross Defense, Unshaken, Pincer Movement, Ice Blade Waltz — and leaves the other 70 identical. Numbers and card text are built when the game loads, so [b]restart the game[/b] after switching.

[h2]Installation[/h2]

1. Subscribe to [b]BaseLib[/b] first (version ≥ 3.4.7).
2. Switch Slay the Spire 2 to the [b]beta branch[/b], then launch the game [b]from Steam[/b].
3. Enable BaseLib and Yetannia in the in-game [b]Mods[/b] list, then restart the game.

Zip version: extract the [code]Yetannia[/code] folder into [code]...\Slay the Spire 2\mods\[/code].

[h2]Notes[/h2]

[list]
[*]Fan work based on Yetannia, a character from the Chinese mobile game 《千年之旅》. Voice and artwork come from the original game; contact me if you would like them removed.
[*]In English, all card / power / relic / keyword text, the settings rows and [b]all 246 lines of Ancient dialogue[/b] are localized. Voice acting is Chinese / Japanese only.
[*]Bug reports: attach the log ([code]%APPDATA%\SlayTheSpire2\logs\godot.log[/code]).
[/list]
