耶坦尼娅 Yetannia — v1.2.0
==================================

【怎么装】

1. 先订阅 BaseLib（Steam 创意工坊），版本要 >= 3.4.8。
   没有它本 Mod 不会加载，而且日志里不会有任何 [Yetannia] 字样。

2. 在 Steam 里把《杀戮尖塔 2》切到 beta 分支（本版本适配 v0.114.0），然后从 Steam 启动游戏。
   直接双击 exe 会报 Steam 初始化失败。

3. 进主菜单后打开 Mod 列表，确认 BaseLib 和 Yetannia 都是「启用」状态。
   游戏可能把新订阅的 Mod 默认设为禁用，没启用就永远不会加载。

4. 重启游戏，选人界面就会出现「耶坦尼娅」。角色不需要解锁，装上就能选。

※ 只通过创意工坊订阅。不要手动把压缩包解压到 mods\Yetannia：
  本地目录会覆盖 / 顶掉创意工坊版（日志里会出现 "loaded both via Steam and local mods directory"），
  导致版本对不上或加载失败。

【这个版本有什么】

- 已适配《杀戮尖塔 2》**v0.114.0** 本体更新（需 BaseLib 3.4.8+）；v0.114 之前的本体无法加载本版本。
- v1.2.0：修复「恐惧模式」选人界面角色名显示成原始 key 的问题（补 shortTitle 本地化）。
- v1.2.0：「先知的手链」在多人合作投票事件中不生效，避免不同玩家选项 / 数据不同步。
- 新角色耶坦尼娅，生命上限 70。
- 初始牌组 10 张：4 打击 + 4 防御 + 回避 + 试探。
- 关键词「先知」：当此牌从抽牌堆进入弃牌堆时，触发它的先知效果。
  （注意：从手牌被弃置不会触发。带「重放」的牌被弃置时会触发同样次数；
  能力牌被弃置触发后会和打出一样离开本场战斗。）
- 初始遗物「先知发饰」：战斗开始时，预见 5。
  （走欧罗巴斯路线换到的先古版「先知头冠」是预见 10。）
- 热修复（v1.1.1）：修复「临时力量」「临时敏捷」名称显示成原始 key 的问题；
  预见监控在战斗结束/极端情况下的日志误报也已收尾。
- 共 82 张卡：基础 4 / 先古 2 / 白 18 / 蓝 32 / 金 24 / 状态 2。
- 新增两个事件：
  - 「记忆先知」：献上自己的记忆，获得事件遗物「先知的手链」；在先知周围祈祷，获得 50 金币。
  - 「调和仪式」（第三层限定，需要所有玩家都带着非永恒诅咒牌）：
    左侧秩序能量 → 移除随机一张非永恒诅咒牌，失去 10% 当前生命；
    右侧混乱能量 → 你每有一张诅咒牌，向卡组加入两张随机升级过的卡牌。
- 新增普通遗物「希楠之约」：每当你消耗一张状态牌，获得 2 点格挡。
- 「先知的手链」改为**事件遗物**：不再从普通遗物掉落里出现，只能在「记忆先知」里获得。
- 「全力进攻」升级效果调整：升级后不再降到 0 费（仍为 1 费），改为获得「保留」。
- 设置里可切换「卡牌数值」：**原版 / 东尼测试版**（目前有 13 张卡两档数值不同），切换后需重启游戏。
  攻击 26 / 技能 37 / 能力 17 / 状态 2。其中 6 张是**联机专属**（单人会自动从牌池里筛掉）。

【联机】

- 本 Mod 现在支持联机。6 张联机专属牌是：
  「先知的指引」(金)、「归途终尽之景」(金)、「身先士卒」(蓝)、
  「先知的援助」(蓝)、「回应愿景之心」(蓝)、「天之恩典」(白)。
- 这 6 张用的是游戏自带的 `CardMultiplayerConstraint`，所以**单人游戏里它们不会出现在
  任何牌池、奖励或商店里**，不需要你手动回避。
- ⚠️ 联机时**所有玩家都要装同一套 Mod 且版本一致**——游戏会在开局比对双方的 Mod 列表，
  不一致会直接拦下来。BaseLib 同理。
- 主机和客机的「卡牌数值」（原版 / 东尼测试版）可以不相同：**客机会在开局前自动改用主机的档位**，
  不会因为两档数值不同而报「数据不同步」。数值当场就一致；卡面文字要等下次启动才跟上，
  而且客机的新档位会写回本地设置，下次启动仍保持主机的档位。
- 其余 76 张卡都是单机牌，联机下也能正常用（各效果的归属都按「谁的牌/谁的能力」判定）。

【这些是占位内容，不是 bug】

- 82 张卡都已经有自己的卡面，不再共用占位图。其中两张先古卡是 608×856 的竖幅大图，
  按它自己的槽位出；其余 80 张是 500×380。
- 有 9 处名字还是占位名（「未命名」开头的那些）：8 个是能力名，1 个是遗物名「未命名·预见」。
  卡牌本身的名字都是正式的，没有占位名。等定名后会改。
- 遗物图标是自制的：6 个遗物各有一套 64×64 / 256×256 图标，不再借用原版的「燃烧之血」。
- 两个新事件（记忆先知 / 调和仪式）的立绘与「希楠之约」的图标目前是**程序生成的占位图**，
  会在后续版本替换成正式美术。
- 卡面上的费用图标、左下角的能量球、地图上的头像也换成了自制图，不再沿用原版。
- 选人立绘是自制贴图；战斗形象 / 休息处 / 商店是自制场景，播的是从模型渲染出来的逐帧动画，
  不再是静态贴图。

【反馈问题时请带上】

- 日志文件：%APPDATA%\SlayTheSpire2\logs\godot.log
  里面所有 [Yetannia] 开头的行都有用，尤其是 self-check 那几十行——
  它们会直接说明 Mod 有没有加载成功、82 张卡有没有注册上。
- 出问题的卡名 + 当时的场面（有几个敌人、你手上有什么、之前触发过几次先知）。
- 如果卡住的是「预见」类卡牌（卡停在屏幕中间不结算），请一并提供日志里的
  [scry] 行。每次预见都会留下一对 「BEGIN / END」；只出现 BEGIN、并且
  10 秒后跟着一条 STILL PENDING 错误，就说明卡死发生在预见那一步。
  BEGIN 行里的 ctx= 是当时的选择上下文类型，inFlight= 是同时有几个预见没结束。

【环境要求】

- 杀戮尖塔 2，版本 >= 0.114.0
- BaseLib >= 3.4.8（创意工坊）
